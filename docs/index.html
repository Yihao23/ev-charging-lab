B1

Simulated charge point

python · cli

The OCPP-facing half of the station. It connects to a CSMS, boots, authorises a tag, opens a transaction, reports meter values on a timer and closes it. It accepts SetChargingProfile and evaluates the whole stack — profile purpose, stack level, watts against amps, a daily recurring tariff — down to one allowed current for the present moment. It tracks each connector’s status, refuses the transitions OCPP 1.6 forbids, holds the error code while a connector is faulted, and suspends rather than trickling when the allowed current falls below the minimum the profile sets.

B3

Wireshark had no V2GTP dissector. I wrote one.

lua · own repo

TCP has no message boundaries, so V2GTP's 8-byte header is the only thing framing the stream — and Wireshark showed it as anonymous bytes. 114 lines of Lua: split the header, name the payload types.

Spans both

One general log analyzer

Both parsers throw the protocol away and keep six fields. correlate() pairs each request with its response by uid and times the gap; anything left unpaired was never answered. Eleven rules read the result: a refusing status or a non-OK ResponseCode, a response slower than the threshold, a heartbeat gap wider than the negotiated interval, a connector transition the state model forbids, messages out of the order ISO 15118-2 defines, a charging session that never closed, a DataTransfer the peer did not process, a station whose two AC ceilings disagree.
